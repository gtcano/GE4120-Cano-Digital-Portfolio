## Activity Description
The activity required us to choose a website concept and create a one-page website using a website-building tool. I chose a business idea and created a website for Gesié Dress Rental, a sample dress rental business.
## What Have I Learned?
I gained experience in using an AI-powered website-building tool to create a website based on my chosen concept. One challenge I encountered was finding a free website-building tool that could generate the type of website I wanted. I also learned how useful these tools can be, especially for beginners who have limited knowledge of website development. They make the process easier and allow users to create websites without having to build everything manually. In the future, I can explore other website-building tools and improve my skills in using them.
