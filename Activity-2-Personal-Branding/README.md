## Activity Description
This activity focused on creating a personal branding kit that represents my personality and professional identity. It included designing a personal logo, creating a tagline, selecting a color palette and typography set and preparing a resume header.
## What Have I Learned? 
Through this activity, I learned how personal branding helps communicate my personality and create a consistent professional image. I also gained experience in designing a logo, choosing suitable colors and fonts and creating a resume header. One challenge I faced was selecting design elements that complemented each other which I addressed by following my chosen theme of Simplicity, Balance, and Growth. In the future, I can apply these skills when creating professional materials and continue improving my personal brand.
